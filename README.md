# Daily Riddle Generator & Solver
A deterministic daily riddle with hints, answers, and the ability to add your own riddles to the pool.
## Features
- 60 hardcoded riddles; daily riddle is seeded by calendar date (consistent per day)
- Show Hint and Reveal Answer buttons
- Random button for extra riddles beyond the daily one
- Submit your own riddle (question + hint + answer) stored in localStorage and added to the pool
## Tech
Static SPA · Tailwind CDN · localStorage
